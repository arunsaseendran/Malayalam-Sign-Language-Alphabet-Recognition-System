# Malayalam Sign Language Alphabet Recognition


This project aims to develop a comprehensive **real-time Malayalam Sign Language
recognition system** that bridges communication barriers for individuals with speech
and hearing impairments. The system combines advanced computer vision techniques
with machine learning to create an accessible mobile application that translates hand
gestures into meaningful Malayalam text and speech output.

## The primary objectives of this research include:
- To design a gesture recognition system that can accurately classify hand signs
corresponding to Malayalam alphabets in real time using smartphone camera input,
ensuring reliable performance across diverse lighting conditions and hand
orientations.
- To develop and train a custom machine learning model using a self-created
dataset of Malayalam sign language gestures, leveraging MediaPipe landmarks and
TensorFlow to classify 50+ Malayalam characters with high accuracy and minimal
latency.
- To implement a robust Android application that seamlessly integrates gesture
detection, alphabet classification, and word prediction capabilities using TensorFlow
Lite for on-device inference and CameraX for efficient camera management.
- To incorporate an intelligent word prediction engine that analyzes sequences of
recognized alphabets and suggests contextually relevant Malayalam words from a
comprehensive lexicon, enhancing communication efficiency and reducing input
time.
- To enable comprehensive speech output functionality using Text-To-Speech
technology for recognized characters and predicted words, providing audio feedback
that facilitates two-way communication and supports users in verbalizing their signed
expressions.
- To create an assistive technology solution that specifically supports users with
communication difficulties, particularly those who rely on sign language, by
establishing an effective bridge between gestural communication and verbal
expression in the Malayalam language context.
